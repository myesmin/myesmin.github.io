# Mohona Yesmin — portfolio

Live at **https://myesmin.github.io**

Hand-built static site: plain HTML, CSS and JavaScript with no framework and no build step.

```
index.html            page content
assets/css/style.css  design system (ink + paper themes)
assets/js/main.js     scroll scenes, Sera scale diagram, hero graph
assets/               favicon and social preview image
```

To preview locally: `python3 -m http.server 8000` and open http://localhost:8000.
